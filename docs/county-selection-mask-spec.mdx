# 縣市選擇與地圖遮罩規格

## 1. 目的

使用者進入 GIS 首頁後，必須先從地圖選擇縣市，系統才啟用交通圖層並依縣市查詢 TDX API。遮罩用來聚焦臺灣與目前選取範圍，避免使用者在尚未建立查詢條件時操作資料圖層。

## 2. 現有資料

- `src/data/Ｔaiwan-country.topo.json` 包含 22 個縣市 geometry。
- 每個 geometry 具有縣市代碼 `id` 與中文名稱 `name`。
- 縣市與臺灣外遮罩共用同一份 geometry，避免邊界不一致。

## 3. 互動狀態

### 尚未選擇縣市

- 顯示臺灣外灰色遮罩。
- 顯示 22 個縣市範圍、hover 狀態與縣市名稱。
- 交通圖層按鈕不可操作，也不發送圖層 API 請求。
- 點擊縣市後記錄縣市名稱並將 View fit 至該縣市範圍。

### 已選擇縣市

- 交通圖層恢復操作。
- 圖層查詢一律使用已選縣市，不再使用寫死的城市。
- 提供重新選擇縣市的入口。
- 行政區遮罩可手動顯示或隱藏；切換遮罩不會清除縣市條件。

### 鄉鎮層級

- 本期不實作 geometry 與 API 篩選。
- 後續允許使用者選擇鄉鎮或跳過，跳過時沿用縣市範圍。

## 4. 分階段範圍

### 階段一：臺灣外遮罩

- 將世界範圍建立為外環，臺灣合併 geometry 作為洞。
- 臺灣以外顯示半透明灰色，臺灣內保持可見。
- 在圖層浮動面板加入獨立的「行政區遮罩」開關，不放入交通資料 catalog。
- 此階段不改變目前 API 查詢行為。

### 階段二：縣市 geometry 與選擇

- 顯示 22 個縣市 geometry、hover 與 label。
- label 使用 geometry 內部點，避免離島或凹多邊形標籤落在區域外。
- 點選縣市後 fit 範圍，並將選取結果提升到頁面狀態。
- 提供重新選擇功能。

### 階段三：鄉鎮選擇

- 暫不實作，保留 `selectedTownship` 狀態邊界。
- 未選鄉鎮時直接使用縣市條件。

### 階段四：依縣市啟用交通圖層

- 初始 `selectedCity` 為 `null`。
- 未選縣市時停用交通圖層按鈕，所有 React Query `enabled` 為 `false`。
- 選取縣市後才使用該名稱查詢所有已開啟圖層。
- 切換縣市時取消舊請求、清除舊圖徵與 popup，再載入新縣市資料。

## 5. 架構邊界

- geometry 解析與遮罩建立放在 `src/service/map/features` 或 `shared`，保持純函式且可單元測試。
- OpenLayers layer 與互動生命週期由地圖 service 管理。
- `TrafficMapPage` 擁有 `selectedCity` 與遮罩可見狀態。
- `LayerPanel` 只顯示狀態並發出操作事件，不直接操作 OpenLayers。
- 後端 API 不需修改，仍接收既有 `city` query parameter。

## 6. 測試策略

- 純函式：TopoJSON 轉換、遮罩 polygon、縣市屬性與 label 點。
- 地圖 service：遮罩顯示切換、縣市選取與 View fit。
- API query options：未選縣市不查詢，切換縣市使用新 query key。
- 人工視覺：遮罩邊界、離島、label 位置、hover 與響應式控制。

## 7. 驗收標準

- 臺灣外部為灰色遮罩，臺灣本島與離島不被覆蓋。
- 遮罩能獨立開關，不影響交通圖層。
- 縣市選取前沒有交通圖層 API 請求。
- 22 個縣市皆可選取並正確 fit。
- 選取後所有交通圖層只查詢該縣市。
- 切換縣市不殘留上一縣市的圖徵或 popup。

## 8. 本期假設

- 遮罩開關放在現有圖層浮動面板，與交通圖層按鈕以 Divider 分隔。
- 第一階段遮罩預設開啟。
- 縣市名稱直接使用 TopoJSON 的 `name`，其格式可傳給現有後端 API。
- 第一階段不強制選縣市；強制流程在階段四一次啟用，避免中間階段破壞既有功能。
